# Engine Demo Script (about 5 minutes)

Run every command from the project root. Have `results/` already generated by `scripts/reproduce.sh`, so no step depends on a live run going well.

## 1. The data (45 seconds)

Show the original Excel sheet beside `all_sheets_cleaned.csv`.

Say: "The timetable was made for people to read on a wall. The engine reads all nine sheets, and {{ROWS_PARSED}} of {{ROWS_RAW}} rows came through. The rest have blank source cells, and we skip them rather than guess."

## 2. A real clash being caught (60 seconds)

```bash
mvn exec:java -Dexec.mainClass="com.university.scheduler.engine.OptimizationRunDriver" > /dev/null 2>&1
grep "rejected booking" logs/scheduler.log | head -3
```

Say: "Each line is a real room or teacher clash in the college's own timetable. The engine rejects it and records why."

## 3. A combined class being merged (45 seconds)

```bash
grep "; " results/*.csv 2>/dev/null | head -2
```

Or open `results/` in Excel, and find a row where the Sections column reads `S1; S2`.

Say: "One teacher, one room, two sections. That is one class, not a clash, so it merges."

## 4. Optimization in action (90 seconds)

```bash
cat results/optimization_summary_42.txt
```

Say: "We add twenty new classes with a fixed seed. Seed 42 places {{S42_SCHED}} of them. The reasons for the rest are listed. Run it again with seed 42 and you get the same numbers."

## 5. Load balancing (60 seconds)

```bash
cat results/balance_summary.txt
```

Say: "Same batch, two strategies. Locking each class to one teacher leaves the load spread at {{NAIVE_SPREAD}}. Letting the optimizer choose among three eligible teachers brings it to {{BALANCED_SPREAD}}. Total load does not change, only how it is shared."

## 6. Proof the code is trustworthy (45 seconds)

```bash
cat results/tests_summary.txt
```

Say: "{{TEST_COUNT}} tests. The property tests run 200 random timetables and check eight rules on every one of them."

## 7. Limits, stated plainly (30 seconds)

Say: "Three things are not finished. Section clashes are not enforced, because the source contains them. Room sizes and the teacher limit are placeholders. Multi-period courses are not modelled. Each is listed in the report with its effect."

## If something fails during the demo

Do not re-run anything live. Show the saved file in `results/` and say the run is recorded there. Showing a saved result that was produced by a script is a better answer than a live error.
